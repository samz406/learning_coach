# 第一版验收

验收日期：2026-09-19。验收范围：教学 Skill、Claude Code / Codex 安装包、学习档案、中文 README。此文记录软件与行为检查，不是学习效果实验。

## 可重复的验收

在仓库根目录执行 `python3 -m unittest discover -s tests -v` 与 `python3 scripts/check_package.py`。测试仅在临时目录写入，不安装到真实用户账号。本次在 Linux / Python 3.12.14 上，15 项 unittest 全部通过；包结构/链接检查和 skill-creator frontmatter 验证通过。

| 项目 | 验收口径 |
| --- | --- |
| 安装 | 两个平台项目路径正确，全部引用资源一并复制；用户级目标路径计算正确 |
| 更新 | 重复安装被拒绝；显式更新备份旧版本，学习档案保持完整 |
| 跨会话 | 独立进程读回目标、待答题、已给提示和下一步 |
| 数据保护 | 过期版本、修改旧作答、损坏快照和写锁均拒绝覆盖 |
| 证据 | 无提示证据缺失、引用错误、帮助程度被重置时拒绝不实标签 |
| 包装 | 标准 frontmatter、引用文件、README 相对链接、Python 语法有效 |

## 行为场景

独立代理使用实际 SKILL.md 与最少输入开展教练对话；每轮只给新的用户输入，不把预期结果放进代理上下文。以下是实际观察，不是预先编写的理想对话。

| 场景 | 实际观察 | 判断 |
| --- | --- | --- |
| 产品设计者带材料学习，只有 10 分钟 | 明确“按用户经验决定页面提示取舍”，只给一个 CSV 导入示例判断任务，等待回答；档案保存为 diagnose | 通过 |
| 用户说“两种人都删掉，不会就自己摸索” | 保留其减少干扰的正确方向，只追问“新手需要额外做什么”，没有一次输出全部练习；原话保存为 partial，标签仍为 exposed | 通过 |
| 用户要求直接给答案、疲劳暂停 | 给出猜格式、反复试错、另找帮助的解释，不再强制出题；保存 paused，待答题 support=answer；明确尚未验证独立应用 | 通过 |
| 全新代理只收到“继续上次，今天 5 分钟”和档案目录 | 读取此前真实档案，说明旧题已看过答案；改用“熟练报销用户遇到新规则”的新情境，等待用户判断，没有重讲整篇材料或把旧题当独立测试 | 通过 |

独立安装检查在带隔离临时目录的项目中执行 README 命令，两处安装各 6 个文件并与源文件逐字节一致；安装后的 state.py 可脱离仓库目录运行。重复安装拒绝覆盖。检查发现项目级安装与首次体验的工作目录衔接不清，已补充“在目标项目启动并使用示例绝对路径”，二次复核通过。

首次工具测试中有一条测试断言因测试数据浅拷贝而失败：保存的数据并未被修改，断言却比较了已被测试自身修改的内存对象。已隔离测试数据并重跑全部 15 项通过；未通过放宽历史保护规则来消除失败。

## 平台未验证项

当前验收环境未安装 Claude Code / Codex CLI，未执行各平台实际选择器发现、账号登录或原生模型多轮测试。安装路径按官方文档核对，目录与文件通过本地工具验证；独立代理行为测试不替代原生宿主测试。Windows 命令与路径采用标准库设计，但未在原生 Windows 运行。

用户本地平台验收：安装后启动会话，调用 `/learning-coach` 或 `$learning-coach`，用示例材料学习一轮，回答后暂停；新开会话从同一档案目录继续。检查能否读到真实回答和帮助程度，且不会重置为零基础。再用另一平台指向同一档案目录续学。
